### Preserved Code Sample: Even Number Summation (`even_number_sum.py`)
```python
# Start the total at zero
total = 0

# Go through every even number from 2 to 100
for number in range(2, 101, 2):

    # Add the current number to the total
    total += number

# Display the final result
print(total)
```
**Verified Output:** `2550`
